Course Overview

This course covers fundamental concepts of database systems including ER modeling, relational model, SQL, normalization, transactions, and concurrency control.

Learning Outcomes

  • Design and implement relational databases.
  • Write complex SQL queries.
  • Understand normalization and indexing.
  • Explain transaction management and concurrency.
